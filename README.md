# A-R4

Educational documentation for the **Arduino UNO R4 WiFi** with simple project ideas organized by skill level.

## What is the Arduino UNO R4 WiFi?

The Arduino UNO R4 WiFi is a microcontroller board that combines:
- The familiar UNO form factor
- Built-in WiFi and Bluetooth Low Energy
- Improved performance compared to older UNO boards

It is a good platform for learning electronics, embedded programming, and connected (IoT) projects.

## Getting Started

1. Install the Arduino IDE.
2. Connect your UNO R4 WiFi board via USB.
3. Select the correct board and port in the IDE.
4. Upload a basic example sketch (such as Blink) to confirm setup.

## Project Categories

### Beginner
Simple, first-step projects focused on basic I/O and core programming concepts.

- **Blink LED**: Learn digital output and timing with `delay()`.
- **Button to LED**: Read a button and control an LED.
- **Serial Hello**: Send messages to the Serial Monitor for debugging.

### Adept
Intermediate projects combining sensors, displays, and structured logic.

- **Temperature Monitor**: Read a sensor and print values over Serial.
- **Mini Weather Display**: Show sensor values on a small display.
- **WiFi Status Indicator**: Connect to WiFi and indicate connection state with LEDs.

### Advanced
Connected and integrated projects that use networking and multi-part logic.

- **IoT Data Logger**: Send sensor data to a web service over WiFi.
- **Home Automation Node**: Control relays/actuators from a network command.
- **Web Dashboard Device**: Host or feed a dashboard showing live board data.

## Learning Path Suggestion

Start with one project in **Beginner**, then complete at least two in **Adept**, and finally build one **Advanced** project tailored to your own use case.
